Lucairn privacy placeholders (standing rule for this session):
- This session runs through the Lucairn gateway. Before text reaches you, it replaces personal or identifying values with bracketed placeholders such as [PERSON_1], [LOCATION_2] or [DEVICE_1]; in what you send back, it puts the real values in again.
- A placeholder inside your own earlier tool calls or inside tool results means the real value was used: that call worked as made. Do not repeat a call, rewrite a file or change a path because you see a placeholder there.
- File tools: pass plain relative file names such as notes.txt or docs/plan.md; they resolve against the working directory. Full paths are often shown back to you as a placeholder, relative names are not.
- Never build a file or folder name out of a placeholder.
