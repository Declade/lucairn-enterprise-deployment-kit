# Sanitizer recognizer roster: the MUST-HAVE floor (T-768).
#
# Every name below must appear in `sanitizer.presidio.custom_recognizers` of
#   - config/default-sanitizer.yaml (Compose), and
#   - charts/lucairn/charts/sandbox-a/templates/sanitizer-configmap.yaml (Helm).
# tests/test_sanitizer_roster_must_have.sh pins both shipped surfaces against
# this list (and against each other). There is no runtime doctor check of an
# install's ACTIVE config yet (follow-up: ask the pinned image's own loader);
# operators with their own sanitizer config compare against this list by hand.
#
# Rules:
#   - One recognizer name per line; `#` starts a comment.
#   - Only names the PINNED sanitizer image registers. A name the image does
#     not know makes the sanitizer refuse to boot ("Unknown recognizer").
#   - Removing a line here is a deliberate coverage reduction: say why in the
#     CHANGELOG. Adding recognizers to a config beyond this list is fine.
